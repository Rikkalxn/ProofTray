# OpenBridge 0.6.10

2026-10-31 · 开发预览发布版 · Android 10+ · ARM64 / x86_64

## 本次版本

- 图库与导入分开，支持预览选片、组合筛选、评分、连拍折叠和同步放大比较。
- 支持 Wi-Fi AP / STA 传图、传输队列与机型支持时的原图断点续传。
- BLE 配对完成后立即检查待传照片；按相机能力选择经典蓝牙连接方向。
- 修正相机名称零字节填充导致的重连匹配失败，以及 Wi-Fi 断开后残留的传输占用。
- Z6 II 传图时切换 BLE / 经典蓝牙，完成后恢复待机；断线时低功耗监听所选相机的待传广播。
- 手动检查可恢复连接并保留结果；图库删除兼容通过 Downloads 保存的 RAW 媒体条目。
- 支持 LUT / 预设导入、批量转换与导出、调用系统编辑器，提供设置与关于页。

## 验证范围

Z6 II + 小米 Android 16 的调试构建已验证：连接后自动下载 3 张便携 JPEG，
随后由连接中的 BLE 通知自动下载新照片，以及 BLE 未连接时由待传广播自动重连并下载。
实际副本尺寸为 1620×1080。新拍 RAW 对应下载的是机内 JPEG 副本，RAW 原片仍留在相机；原图通过 Wi-Fi 获取。
RAW 删除已通过应用与 Android 系统确认验证，只删除所选手机文件。

Release 构建不包含调试广播接收器，使用独立发布证书签名。
本次发布执行 APK 构建及产物检查，没有重跑静态分析或测试套件；Release APK 未覆盖安装到现有调试手机。
长期后台稳定性、功耗、GPS 和更多机型还需实测。RAW 解码渲染与 DNG 转换尚未接入。

## 安装与更新

APK 包名为 `org.openbridge.app`，版本名 `0.6.10`，versionCode 为 `17`。
同一发布证书签名的后续版本可覆盖更新。现有调试安装使用另一张证书，Android 会拒绝直接覆盖。
不要为尝试覆盖而清除现有应用数据；建议先在另一设备或独立 Android 用户中试用发布版。

发布 ZIP 包含已签名 APK、对应提交的源码 ZIP、发布说明、构建信息、第三方声明和 SHA-256 校验文件。
签名密钥与密码仅留在维护者本机的 `private/signing/`，不进入 Git 或发布包；需单独备份以持续发布更新。
