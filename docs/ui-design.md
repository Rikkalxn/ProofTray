# OpenBridge 界面规范：Material 3 Expressive

当前界面采用 Jetpack Compose + 官方 Material 3 Expressive（M3E），没有迁移业务或相机协议。

## 主题

- 入口：`ui/BridgeTheme.kt` 的 `MaterialExpressiveTheme`。
- 随系统切换明暗；Android 12+ 使用系统动态配色，更低版本使用统一紫色系后备方案。
- 文字、按钮、卡片与弹窗均取 Material 语义颜色；照片上的标记使用半透明黑底白字，保证复杂画面上的可读性。
- 圆角统一为 8 / 12 / 20 / 24 / 32 dp，分别用于微小元素、图标容器、照片卡片、内容分组和主要面板。
- 内容页水平留白 20 dp，内容卡片内边距 20 dp，组间 16 dp；底部面板水平留白 24 dp。
- 主要操作高度至少 56 dp，使用 Expressive 按压形变；其他操作沿用 Material 的触控尺寸。
- 使用 Expressive 加载指示器、浮动工具栏和默认动效体系，不自行加入持续装饰动画。

## 页面与操作层级

| 页面 | 主要职责 | 主要操作 |
| --- | --- | --- |
| 图库 | 已导入原片、分组、管理 | 调色、比较、导出、移除、删除手机文件 |
| 导入 | 相机候选、已导入识别、导入前筛选 | 按批加载、选片、导入原片、移除候选或清空选片列表 |
| 相机 | 连接状态、Wi-Fi 模式、蓝牙配对 | 连接相机；高级参数和首次登记按需展开 |
| 任务 | 相机下载和本地导出 | 查看状态、暂停、取消、重试、打开结果 |
| 设置 | 下载策略、功耗、位置、设备与关于 | 各能力独立启用；连接配置与实际状态分开显示 |

筛选与导出采用相同的底部面板，动作区固定在底部；简单命名和确认使用标准对话框。
多选工具栏使用官方 `HorizontalFloatingToolbar`，放在底部导航上方。
配对码确认仍要求用户核对机身，界面调整不改变确认流程。
比较界面继续使用中性黑色图像视口，保留同步缩放、独立缩放与复位。

“图库 / 导入 / 相机 / 任务 / 设置”在底部导航并列，两个照片范围的筛选条件独立，顶部不再重复切换范围。
单击图片打开单张查看；长按或选择圈进入选片，多选时点击图片切换选中。
导入默认显示“未导入”，离线缓存需要显式打开。
选片工具栏第一行直接显示“清除选择 / 移除 / 删除”；评分独立按钮展开清除评分及 1–5 星。
移除确认说明保留文件；删除确认说明仅删除所选手机文件。Android 11+ 继续交给系统确认，远程候选不允许删除。
目录分页与单次导入数量使用同一个 25 / 50 / 100 / 200 上限；提示筛选仅覆盖已加载范围。

设置中自动下载默认关闭，可预先选择蓝牙便携 JPEG 或 Wi-Fi 原图格式。手动导入格式独立保存。
省电 / 均衡 / 及时显示实际查漏和定位间隔；GPS 默认关闭，只有显式启用时申请精确位置权限。
BLE 控制地址与经典蓝牙传图地址分开选择。系统配对由系统页面管理；应用内关联清理不等于取消系统配对。
关于页为独立页面，包含品牌、实际包版本、功能入口说明、复制应用信息、快速上手及开源许可。
快速上手和许可文本使用底部面板；整体项目许可证仍待确定，随包保留 furble MIT 文本。

## 品牌图标

- 标志由打开的照片边框、桥拱与一枚薄荷绿圆点组成。背景紫色 `#50379B`，辅助色 `#BEECDD`。
- Android 前景使用 VectorDrawable，108 dp 画布内保留安全区域；Android 13+ 另有单色图层，通知使用简化的透明底单色标志。
- 矢量源文件为 `design/brand/openbridge.svg`；Android 文件位于 `res/drawable/ic_launcher_foreground.xml` 等资源中。
- 关于页复用同一前景资源，不用另一套图形。页面其他部分继续遵循系统动态配色。
- 图标按 [Android 自适应图标规范](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive) 制作。

调色继续使用 M3E 组件：全屏中性灰预览、原图切换、基础风格及强度 / 曝光 / 对比度 / 饱和度 / 冷暖滑杆。
控件区域可滚动，为横屏和较大字号保留预览空间。LUT 库与预设导入沿用底部面板。
“用于导出”选择一组参数，批量导出面板显示预设名称并允许关闭；不会立即修改源照片。
系统编辑放在选片工具栏更多菜单中；只有选中单张照片时启用，需先下载原片。

## 依赖版本

使用官方 `androidx.compose.material3:material3:1.5.0-alpha09`。
这是预发布依赖，选用它是为了兼容本项目现有 SDK 36 / AGP 8.13.2；已核对该 AAR 最低要求为 SDK 35 / AGP 8.6。
本次核对的较新 `1.5.0-beta02` 要求 SDK 37 / AGP 9.1，暂不把界面调整扩展为整套工具链升级。
主界面不依赖外部图标字体或在线字体，统一线形图标由 Compose Canvas 绘制。

## 验证

- 编译检查 Expressive API、现有对话框和相机动作接线。
- 使用已连接手机检查照片空状态、相机页、任务页、筛选底部面板及系统栏颜色。
- 手机锁屏时不尝试绕过解锁；视觉检查等待用户解锁后继续。
- 安装使用 `adb install -r`，保留已有照片目录、评分和任务数据。
